# 🌌 Аккреция

Мини-игра для Telegram и браузера: сформируй звёздную систему от молекулярного облака до целой галактики.

[![Играть](https://img.shields.io/badge/🎮_Играть-GitHub_Pages-6b4de6?style=for-the-badge)](https://YOUR-USERNAME.github.io/accretion-game/)

## 📖 О чём

Idle-симулятор эволюции космоса в 6 фаз:
1. **Молекулярное облако** — удерживай палец, собирай пыль
2. **Протопланетный диск** — крути пальцем, раскручивай диск
3. **Протозвезда** — тапай, держи жар
4. **Первая планета** — собери из шаров-частиц
5. **Формирование системы** — 8 планет, слияния, столкновения
6. **Галактика** — строй новые системы, открывай Прайм-объекты

## 🎮 Управление

- **Удержание** — тянет пыль
- **Кручение** — раскручивает диск
- **Тап** — нагрев, слияние
- **Пинч** — зум
- **Двойной тап** — сброс камеры

## ✨ Особенности

- 🌀 Физическая симуляция — пыль реально тянется к звезде
- 🌟 Прайм-объекты — 11 типов (Чёрные дыры, Квазары, Пульсары, Кротовые норы)
- 🎨 Процедурная графика — каждая планета уникальна
- 💾 Полностью offline — работает без интернета
- 📱 Мобильный-first — оптимизирован для Telegram Mini App
