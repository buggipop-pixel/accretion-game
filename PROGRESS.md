## Сессия: «Активная оборона» — списание по «Готово», статистика, флот вместо ВКЛ

**Проблема:** металл за уровень автообороны списывался сразу по клику; окно «Ночной режим» показывало устаревшую статистику «потерь»; кнопка ВКЛ/ВЫКЛ дублировала управление обороной; оборона сбрасывалась при возврате игрока.

**Что сделано:**
- `js/ui.js` — выбранный уровень хранится в `_tempNightConfig.defenseLevel`, металл списывается только в `saveNightConfig()` по «Готово»; проверка баланса и повторное нажатие = обновление срока.
- Окно переименовано в **«🛡 Активная оборона»** (настройки, заголовок, welcome-текст, тост возврата).
- Кнопка «ВКЛ/ВЫКЛ» заменена на «Активировать/Отключить флот» → `toggleFleet('night')`.
- «Прогноз защиты» пересобран под реальные механики: шанс, разбивка оборона/флот/экспедиция, офлайн-частота, кража до 90 мин, кап −80%, 40% ресурсов, планеты, 10 ч.
- Пресеты показывают шанс трофея; из `NIGHT_CFG` убраны неиспользуемые `lossCaps`, `damagePerHit`, `presets.defense`.
- `js/economy.js` — оборона больше не сбрасывается при возврате: живёт свои 10 ч, ночные миссии сбрасываются отдельно.
- `js/state.js` — `defenseEnabled` всегда true (тумблер убран).
- `tests/fleet-visual-test.js` — +6 тестов на отложенное списание, переименование, разметку, сохранение срока (30/30).

**Проверка:** `node tests/fleet-visual-test.js` — 30/30; полный набор — 13/13 сьютов без провалов.

**Что сделано:**

## Сессия: защита Прайм-систем (вспышка + вторжения)

**Проблема:** при тесте вспышки сверхновой из двух Прайм-объектов (кротовая нора 3 ур. + чёрная дыра) выживала только чёрная дыра. Плюс Прайм-системы могли быть целью вторжения и получать урон, как обычные.

**Причина:**
1. `performSupernova()` сохраняла только записи из `S.otherSystems` с флагом `isPrime`. Прайм на активной (в т.ч. родной) системе жил в `S.primeSystem` и в сейв не попадал — после вспышки терялся.
2. Старые сейвы могли хранить `primeData` без флага `isPrime` — система считалась обычной и вылетала по лимиту.
3. `spawnInvasion()` включал Прайм-системы в список целей; `applyInvasionAftermath()`, `applyInvasionHit()` и `applySystemLosses()` могли повреждать планеты Прайма.

**Что сделано:**
- `js/state.js` — единые хелперы `isPrimeSystemData()`, `primeDataOfSystem()`, `isPrimeSystemAt()`, `bestPrimeWormholePct()`, `markPrimeSystem()`; миграция сейвов нормализует `primeData` ↔ `isPrime` (в т.ч. для родной системы).
- `js/prestige.js` — при вспышке сохраняются ВСЕ Прайм-системы: активная/родная (`S.primeSystem`), записи из `otherSystems[0..]`, в т.ч. без флага `isPrime`. Бонус кротовой норы берётся от лучшей норы среди всех Праймов. Праймы не входят в лимит обычных систем.
- `js/invasions.js` — вторжения больше не выбирают Прайм-системы целью; старые атаки на Прайм снимаются без урона; урон планет применяется к атакованной системе, а не всегда к активной.
- `js/economy.js` — офлайн-урон и «потери систем» не трогают Прайм.
- `js/ui.js`, `js/main.js` — Прайм в списке систем и на карте определяется и по `primeData`, а не только по `isPrime`.
- `tests/prime-protection-test.js` — регрессионные тесты (вспышка с активным/родным Праймом, сейв без `isPrime`, вторжения). Добавлен в `npm run test:all` и `npm run test:prime`.

**Проверка:** `node tests/prime-protection-test.js` — 15/15; полный набор тестов — без провалов.
